# Procedural art pipeline

Art is generated by checked-in Blender Python scripts, not hand-sculpted
`.blend` files. This keeps every asset regenerable, diffable, and buildable
by an agent without a GUI.

## Layout

```
art/blender/
  scripts/    one .py generator per asset family (bowl.py, table.py, ...)
  out/        generated .glb files (gitignored render cache aside; the .glb
              outputs themselves are committed via Git LFS once they're
              imported into the Unity project under Assets/Art/Generated/)
  Makefile    `make all` regenerates everything headless
```

## Running a generator

```bash
# one variant
/Applications/Blender.app/Contents/MacOS/Blender --background \
  --python scripts/bowl.py -- --variant regular

# every variant a script defines
make all
```

Each script is **parametric**: variants are data (a dict of dimensions/
options), not separate hand-edited geometry. Changing "make the bowls
wider" is a one-line diff to the variant table, not a remodel.

## Why procedural, and its limits

Parametric hard-surface geometry (tables, counters, shelves, stoves,
fridges, crates, the shophouse shell) is where this approach is strong —
regular forms, repeatable variants, cheap iteration.

It is **not** a good fit for organic geometry (food close-ups, herbs,
steam) or human characters (customer NPCs), where visual judgment matters
more than parametric rules. See `docs/architecture.md` §"Where AI-generated
art works" in the bootstrap plan for the fallback plan there (AI 3D
generation via Hyper3D/Rodin, a stylized NPC asset pack, or a commissioned
artist) — decided at the Fun Gate, not before.

## Blender MCP (interactive/exploratory use)

For interactive sculpting, viewport screenshots, and scene inspection, the
official Blender Lab MCP server is registered with Claude Code as
`blender-mcp`. It requires a running Blender instance with the `mcp`
extension enabled (already installed into the `user_default` extension
repo — see repo root for how it was set up). Anything produced this way
that matters gets folded back into a script here; MCP output itself is not
the source of truth.
